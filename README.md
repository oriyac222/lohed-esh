# לוכד אש — דף נחיתה סטטי

## הפעלה מקומית

פתחו את `index.html` בדפדפן, או העלו את כל תוכן התיקייה לשרת סטטי או למאגר GitHub.

## פרסום

העלו את הקבצים והתיקייה `assets/` יחד, ללא שינוי במבנה הקבצים.

## טופס יצירת קשר

הטופס מחובר ל-Formspree באמצעות `POST` ל-`https://formspree.io/f/maenyaea`. כל שדה בטופס כולל `name` מתאים, כדי שהפנייה תגיע לחשבון Formspree שלך. יש לבדוק לאחר הפרסום שהחשבון פעיל ושפניות מגיעות כנדרש.

## מידע שעדיין דרוש

- אזורי השירות
- כתובת מדיניות פרטיות ותנאי שימוש
- הגדרות גישה ושמירת נתונים בחשבון Formspree
